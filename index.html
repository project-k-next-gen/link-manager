Before you begin, you need to set up the backend API.

1

Create Google Sheet

Go to Google Sheets and create a new spreadsheet. Copy the Spreadsheet ID from the URL.

2

Create Apps Script

Go to Google Apps Script, create a new project, paste the backend code, and add your Spreadsheet ID.

3

Deploy Web App

Deploy the script as a Web App (Execute as: Me, Access: Anyone) and copy the URL.

4

Enter API URL Below

Paste your Web App URL in the field below to connect the app.

Example: https://script.google.com/macros/s/AKfycb.../exec
